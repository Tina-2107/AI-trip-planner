# AI Trip Planner

An AI-powered trip planner built with **React + Vite**, **FastAPI**, and **Gemini**.

## Project Structure

```text
ai-trip-planner/
├── frontend/     # React + Vite frontend
└── backend/      # FastAPI backend
```

## Tech Stack

- **Frontend:** React + Vite
- **Backend:** FastAPI
- **AI:** Google Gemini
- **Language:** JavaScript + Python

## Architecture

The application follows a frontend → backend → AI → backend → frontend flow.

```text
                         USER
                           │
                           ↓
                     TripForm.jsx
                           │
                           │ prompt
                           ↓
                        api.js
                           │
                           │ POST
                           ↓
                    FastAPI Backend
                           │
                           ↓
                     Gemini Service
                           │
                           ↓
                   Structured JSON
                           │
                           ↓
                       Validation
                           │
                    ┌──────┴──────┐
                    │             │
                  valid         invalid
                    │             │
                    ↓             ↓
                React State     Error
                    │
                    ↓
                 TripView
                    │
              ┌─────┼─────┐
              ↓     ↓     ↓
           Expand  Remove  Reorder
```

### Component Responsibilities

| Component       | Responsibility                                                   |
| --------------- | ---------------------------------------------------------------- |
| `TripForm.jsx`  | Collects trip requirements from the user                         |
| `api.js`        | Sends API requests from React to FastAPI                         |
| FastAPI Backend | Handles API requests and communicates with Gemini                |
| Gemini Service  | Generates the travel itinerary                                   |
| Structured JSON | Provides a predictable format for the frontend                   |
| Validation      | Checks whether the generated response has the expected structure |
| React State     | Stores the generated itinerary                                   |
| `TripView`      | Displays and manages the itinerary                               |
| Expand          | Shows additional itinerary details                               |
| Remove          | Removes an activity/day from the itinerary                       |
| Reorder         | Changes the order of itinerary items                             |

## Setup

### 1. Clone the repository

```bash
git clone <your-repository-url>
cd ai-trip-planner
```

### 2. Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

The frontend runs on:

```text
http://localhost:5173
```

### 3. Backend Setup

Open another terminal:

```bash
cd backend
python -m venv venv
```

Activate the virtual environment.

**Windows:**

```bash
venv\Scripts\activate
```

**macOS/Linux:**

```bash
source venv/bin/activate
```

Install the required dependencies:

```bash
pip install fastapi uvicorn google-genai python-dotenv
```

### 4. Gemini API Key

Create a `.env` file inside `backend/`:

```env
GEMINI_API_KEY=your_gemini_api_key
```

Do **not** commit `.env` or your API key to Git.

Add the following to `backend/.gitignore`:

```text
.env
venv/
__pycache__/
```

### 5. Start the Backend

From the `backend/` directory:

```bash
uvicorn main:app --reload
```

The API runs on:

```text
http://127.0.0.1:8000
```

FastAPI documentation:

```text
http://127.0.0.1:8000/docs
```

## API Flow

The first milestone establishes this complete flow:

```text
React
  ↓
FastAPI
  ↓
Gemini
  ↓
FastAPI
  ↓
React
```

The React frontend sends a trip-planning prompt to the FastAPI backend.

FastAPI sends the prompt to Gemini.

Gemini generates a structured itinerary.

The backend validates the generated response and returns it to React.

React stores the result in state and displays it through `TripView`.

## Example Request

Input:

```text
5 day trip to Goa focused on beaches
```

## Example Response

```json
{
  "destination": "Goa",
  "days": [
    {
      "day": 1,
      "activities": ["Baga Beach", "Calangute Beach"]
    },
    {
      "day": 2,
      "activities": ["Palolem Beach", "Patnem Beach"]
    }
  ]
}
```

The exact itinerary may vary because it is generated by Gemini.

## Validation

The Gemini response should follow the expected structure:

```json
{
  "destination": "string",
  "days": []
}
```

If the response is valid:

```text
Gemini
   ↓
Structured JSON
   ↓
Validation
   ↓
React State
   ↓
TripView
```

If the response is invalid:

```text
Gemini
   ↓
Invalid Response
   ↓
Validation
   ↓
Error
```

This prevents unexpected AI output from breaking the frontend.
